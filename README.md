# Facial Recognition Based Attendance System

A Python and OpenCV based facial detection attendance system.

## Technologies

- Python
- OpenCV
- NumPy

## Features

- Real-time camera access
- Face detection
- Face bounding boxes
- Camera close using Q or ESC
- Attendance system foundation

## Project Status

Currently, the project implements real-time face detection using OpenCV.
Future versions will include face recognition, attendance recording, and location tracking.

## How to Run

1. Create and activate the Python virtual environment.
2. Install the required dependencies.
3. Run the application:

```bash
python face_attendance.py
